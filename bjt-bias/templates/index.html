Week 2 Goal

Rough target for this lab: Build a Flask web app that takes the circuit parameters, computes the BJT DC bias (VB, VE, VC, VCE, IB, IC, IE) for a common-emitter amplifier with voltage-divider bias, and displays the results.

สูตรอ้างอิง (Thevenin)

VBB = VCC·R2/(R1+R2), RB = R1||R2, IB = (VBB−VBE)/(RB + (1+β)RE)

IC = βIB, IE = (1+β)IB, VC = VCC−IC·RC, VE = IE·RE, VCE = VC−VE

สมมติ VBE คงที่ตามที่ป้อน และใช้แบบจำลองเชิงเส้น (หากอิ่มตัว/คัตออฟ ค่าที่แสดงเป็นผลจากแบบจำลองและมีคำเตือน)
