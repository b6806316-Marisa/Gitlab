{% if mode == "fixed" %}

สูตรอ้างอิง (Fixed Bias)

IB = (VCC − VBE) / RB, IC = βIB, IE = (1+β)IB

VE = 0, VB = VBE, VC = VCC − IC·RC, VCE = VC

{% elif mode == "emitter" %}

สูตรอ้างอิง (Emitter Bias)

IB = (VCC − VBE) / [RB + (1+β)RE], IC = βIB, IE = (1+β)IB

VE = IE·RE, VB = VE + VBE, VC = VCC − IC·RC, VCE = VC − VE

{% else %}

สูตรอ้างอิง (Voltage Divider Bias)

VTH = VCC·R2/(R1+R2), RTH = R1||R2, IB = (VTH−VBE)/(RTH + (1+β)RE)

IC = βIB, IE = (1+β)IB, VC = VCC−IC·RC, VE = IE·RE, VCE = VC−VE

{% endif %}

สมมติ VBE คงที่ตามที่ป้อน และใช้แบบจำลองเชิงเส้น (หากอิ่มตัว/คัตออฟ ค่าที่แสดงเป็นผลจากแบบจำลองและมีคำเตือน)
