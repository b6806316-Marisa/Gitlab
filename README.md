# DC Circuit Calculator

เครื่องมือคำนวณวงจรไฟฟ้ากระแสตรง รองรับตัวต้านทานแบบอนุกรมและขนาน โดยแสดงความต้านทานรวม กระแสรวม กำลังไฟฟ้ารวม และค่าของตัวต้านทานแต่ละตัว

## วิธีใช้งาน

ต้องติดตั้ง Python 3 แล้วรันคำสั่งจากโฟลเดอร์โปรเจกต์:

### กรอกข้อมูลหลังเริ่มโปรแกรม

```powershell
py electrical.py
```

โปรแกรมจะถามรูปแบบวงจร (`series` หรือ `parallel`), แรงดัน และค่าความต้านทาน สามารถกรอกตัวต้านทานหลายค่าโดยคั่นด้วยเครื่องหมายจุลภาค เช่น `2, 4` ได้

### ส่งค่าผ่านคำสั่ง

```powershell
python electrical.py <แรงดันโวลต์> <ความต้านทานโอห์ม> [ความต้านทานโอห์ม ...] [--mode series|parallel]
```

ตัวอย่างวงจรอนุกรม 12 V กับตัวต้านทาน 2 ohm และ 4 ohm:

```powershell
python electrical.py 12 2 4
```

ตัวอย่างวงจรขนาน:

```powershell
python electrical.py 12 2 4 --mode parallel
```

โหมดเริ่มต้นคือ `series` ค่าความต้านทานแต่ละตัวต้องมากกว่าศูนย์ และแรงดันต้องไม่ติดลบ
